# MewAgent v0.2 发布验收清单

> 用途：v0.2.0 发布前的最后一道门。逐条勾选并写证据位置；任何 P0 未过不得发布。
> 配套：[plan.md](./plan.md) §2.3（12 条成功标准）、[testing.md](./testing.md) §4（阶段回归）。

---

## 0. 使用方式

1. 在 `docs/v0.2/tasks.md` 的 V2-5-5 开工。
2. 逐条执行本清单，把"证据"列填成命令输出摘要/截图路径/提交哈希。
3. 全部 P0 为 ✅ 后，才能打 `v0.2.0` tag、执行 `npm publish`。
4. 勾选结果与发布记录写进 HANDOFF §7。

判定：✅ 通过；⚠️ 带缺陷通过（必须记录缺陷号与影响）；❌ 不通过（阻塞发布）。
